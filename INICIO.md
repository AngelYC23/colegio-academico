# Inicio del proyecto

La guía vigente para el taller y para este Mac está en [app/README.md](app/README.md).

Desde la raíz del repositorio:

```sh
cd app
./iniciar.command
```

Abre http://127.0.0.1:8088/ingresar. Si ya está abierto, solo recarga la página.

La configuración local utiliza PHP de XAMPP y SQLite. El procedimiento alternativo con Docker/MySQL está en [README.md](README.md). Las cuentas institucionales para la presentación se explican en [app/ACCESO.md](app/ACCESO.md).

El alcance actual comprende usuarios y roles, estudiantes, profesores, encargados, estructura académica, inscripciones, asignaciones, calificaciones e informes. El alcance final del taller debe contrastarse con el enunciado del docente.

Los documentos de `odd/tasks/` conservan el registro histórico de otra instalación en Windows; sus rutas, puertos y estado de la base no corresponden a este Mac.
